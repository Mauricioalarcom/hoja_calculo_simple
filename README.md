# hoja_calculo_simple

## Comandos de Operación

Se han asignado combinaciones de teclado para realizar operaciones de manera rápida sobre la selección actual (ya sea una celda individual o un bloque/rango de celdas).

Para desencadenar una operación, utiliza el siguiente atajo de teclado dependiendo de tu sistema operativo:
- **Windows / Linux**: `Ctrl + P`
- **macOS**: `Cmd + P` (o `Ctrl + P`)

### Comportamiento del atajo:
1. **Consulta de celda sencilla**: Si tienes seleccionada una única celda en la grilla y presionas el atajo, el programa ejecutará una consulta (`Consultar`) sobre dicha celda y mostrará su valor.
2. **Suma de rango**: Si mantienes presionado el botón izquierdo del mouse y arrastras para seleccionar un rango/bloque de celdas, al presionar el atajo de comandos se ejecutará por defecto la operación `SUMA` sobre todos los elementos seleccionados en ese rango.

*Nota:* Puedes escribir valores en las celdas usando los paneles de texto superiores antes de aplicar los comandos correspondientes.
